# Thunderstorm Comfort storybook state art

The four transparent sprites in this folder are reviewed source copies for the runtime
`ArenaFinal/Props/Thunderstorm` state sequence. They were generated with the built-in image
generation tool on 2026-07-23, then chroma-keyed with the repository image-generation helper.

Shared art direction: compact top-down charcoal/lavender storm cloud over a folded teal comfort
blanket, warm brown outlines, flat-cel storybook shading, transparent background, no characters,
text, letters, or UI. State-specific prompts added:

- waiting: two separated gold/brown paw motifs;
- thunderclap: a readable yellow bolt and sparse blue sparks;
- comfort huddle: an open U-shaped bed, paired paw prints, and a small heart;
- storm cleared: sun, pale clouds, and restrained celebratory sparkles.

Runtime sizing is authored by world width in `ThunderstormComfortMissionController`, so source
resolution changes cannot make the cue disappear or balloon to room scale.
