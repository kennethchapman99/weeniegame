# Generated Level Area Prop Pack

Couch-test transparent cartoon level plates for missions whose spaces should not read as the generic backyard.

- `kitchen_floor_area` and `kitchen_counter_wall` stage Kitchen Falling Food Frenzy as an indoor kitchen around the controller-owned counter and safe bowl. Blanket Catch reuses `kitchen_floor_area` directly (V3.4) since its briefing is the same kitchen counter.
- `car_interior_cabin` and `car_balance_lane` (RETIRED 2026-07-14): replaced by the Car Ride Chaos backseat set in `ArenaFinal/Props/CarRide/` (see `Assets/Art/ReferenceOnly/GeneratedCarBackseat/`), generated by `tools/art/generate_car_backseat_pack.py`.
- `diningroom_floor_area` (V3.4, 2026-07-19) stages Table Stealth's dinner-table steak heist. `livingroom_floor_area` (V3.4, 2026-07-19) stages both Chaos Machine's Rube Goldberg den and Thunderstorm Comfort's storm-shelter huddle, which share one den fantasy per their briefing art. Both generated by `tools/art/generate_indoor_level_area_packs.py`.

These are generated placeholder assets for readability review. Controller-owned markers, colliders, and deterministic mission state remain authoritative.
