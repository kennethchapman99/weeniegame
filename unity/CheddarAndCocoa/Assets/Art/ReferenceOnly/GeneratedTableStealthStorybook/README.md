# Table Stealth Storybook State Family

Reviewed transparent sources for the dining-room heist. Runtime copies are promoted by
`tools/art/promote_table_stealth_storybook.py`.

- Human states keep one friendly adult, blue shirt, honey-oak table, and burgundy runner:
  watching the plate, turning toward the distraction, comically spotting the theft, and
  playful arms-folded capture. No punishment or menace.
- Steak states keep one cream plate with a burgundy rim: available with aroma, sliding off
  during sneak progress, and an empty crumb/smear read after success.
- All assets use the established warm storybook cel treatment, dark brown outlines, restrained
  highlights, transparent backgrounds, and no embedded text or UI.
- Runtime authored widths are 4.4 world units for the human/table vignette and 1.8 for the plate.
  The attachment helper cancels marker non-uniform scale so these square sources remain square.
